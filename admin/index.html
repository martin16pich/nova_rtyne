Chybí nastavení služby

V souboru config.js je potřeba doplnit Supabase Project URL a publishable key. Nezadávejte žádný tajný klíč.

Přihlášení správce

Správa webu je přístupná pouze pozvaným správcům. Hlavní správce používá e-mail martin16pich@gmail.com.

Nastavit vlastní heslo

Přijali jste pozvánku nebo otevřeli odkaz pro obnovení hesla. Zvolte si nové heslo, které budete znát jen vy.

Účet nemá oprávnění

Účet je přihlášený, ale nebyl schválen jako správce. Po přijetí pozvánky zkuste stránku obnovit.

Úprava programu

Změny se po uložení zapíší přímo do zabezpečené databáze. Web je následně automaticky načte. Nepotřebujete nahrávat nový HTML soubor na GitHub.

Vyberte programový bod vlevo.

Schvalování nápadů občanů

Neschválené návrhy jsou přístupné pouze správcům. Po schválení se jméno, návrh a případná příloha zobrazí na webu.
