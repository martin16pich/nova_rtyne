Zvolte záložku a bod, upravte text nebo stav a stáhněte aktualizovanou verzi webu.

Bezpečnost: Otevření této adresy není přihlášení. Tato stránka je veřejně dostupná každému, kdo zná její adresu; umožňuje pouze připravit a stáhnout soubor. Zveřejnit změny může pouze člověk s právem upravovat váš repozitář GitHub. Nikam sem nezadávejte hesla ani osobní údaje občanů.

Postup: Upravte položky → stiskněte „Stáhnout aktualizovaný index.html“ → na GitHub.com otevřete svůj repozitář → Add file → Upload files → nahrajte nový index.html do hlavní složky → Commit changes. Po zveřejnění aktualizujte stránku.
